# 價值觀競標遊戲（教會活動用）

這是一個給教會活動使用的線上競標遊戲。分成三段、每段 7 題（共 21 題），
玩家用手機瀏覽器加入，用籌碼互相喊價，系統自動跑「第一次／第二次／第三次成交」流程。

## 三個頁面

| 頁面 | 網址 | 用途 |
|---|---|---|
| 玩家頁面 | `/` | 30 位參加者用自己的手機開這個網址，輸入名字加入，用來喊價 |
| 管理者頁面 | `/admin` | 主持人（1人）用，登入密碼後可以選題、控場、看所有人籌碼 |
| 投影頁面 | `/display` | 接投影機/電視給全場看，會顯示目前題目、價格、喊價階段；開場前會顯示加入用的 QR Code |

管理者密碼預設是 `church2026`（可在部署時改，見下方「修改管理者密碼」）。

## 遊戲規則（已寫進程式）

- 每人籌碼 365 萬。
- 21 題分三段：生活價值 / 身心價值 / 與主的價值，各 7 題。題目文字在 `data/items.json`，可自行修改。
- 玩家輸入數字喊價（單位：萬），喊價必須高於目前價格、且不超過自己剩餘籌碼。
- 有人喊價後：等 3 秒喊「第一次」→ 若無人加價，再等 7 秒喊「第二次」→ 若無人加價，再等 15 秒喊「第三次，成交！」
- 過程中只要有人加價，就整個重新從等 3 秒開始算。
- 成交後，得標者的籌碼會自動扣款。
- 管理者可以隨時選任何一題開標（不用照順序），可以取消流標，可以在最後按「結束整場遊戲」讓所有畫面切到結算提示，接著手動切換到教會信息簡報（PPT）。

## 修改 21 題的內容

打開 `data/items.json`，每一題就是一個 `{ "id": "...", "title": "..." }`，
把 `title` 改成你要的文字即可，不需要改程式。id 不要重複、不要有空白。

## 部署到免費雲端平台（推薦：Render）

Render 有免費的 Web Service，可以跑這種需要即時連線（Socket.io）的網頁遊戲，
30 個人都用手機連網路（4G 或現場 WiFi 皆可）就能加入，不需要你自己架伺服器。

### 步驟

1. 把這個資料夾上傳到 GitHub（一個新的 repository 即可，設為 Public 或 Private 都可以）。
   - 沒有 GitHub 帳號的話先到 https://github.com 免費註冊。
2. 到 https://render.com 用 GitHub 帳號免費註冊/登入。
3. 點 **New +** → **Web Service**，選你剛剛上傳的 repository。
4. 設定：
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
   - **Instance Type**：Free
5. （建議）在 **Environment Variables** 加一個 `ADMIN_PASSWORD`，設定你自己的管理者密碼，
   例如 `ADMIN_PASSWORD=你自己的密碼`。如果不設，預設密碼是 `church2026`。
6. 按 **Create Web Service**，等它部署完成（通常 2-5 分鐘），會拿到一個網址，例如：
   `https://church-value-auction.onrender.com`

### 活動當天要注意

- **免費方案閒置會睡著**：如果一段時間沒人連線，Render 免費服務會休眠，
  下次有人連線時要花約 30-60 秒喚醒。**建議活動開始前 10 分鐘，管理者自己先打開網址一次**，
  把服務叫醒，確認可以正常運作，再讓大家掃 QR Code 加入。
- 投影頁面 (`/display`) 在還沒開始任何一題之前，會自動顯示加入用的 QR Code，
  可以先把投影頁面打開讓大家掃碼加入等待。
- 全程只要大家手機有網路（行動網路或教會 WiFi 都可以）就能玩，跟藍牙沒有關係。

## 想先在自己電腦上測試（可跳過，非必要）

需要先安裝 [Node.js](https://nodejs.org)（LTS 版本即可）。

```
npm install
npm start
```

啟動後，同一台電腦瀏覽器開 `http://localhost:3000` 是玩家頁面，
`http://localhost:3000/admin` 是管理者頁面，`http://localhost:3000/display` 是投影頁面。

如果想讓同一個 WiFi 底下的其他手機也能連（不透過雲端），
把網址的 `localhost` 換成你電腦的區域網路 IP（例如 `192.168.1.5:3000`）即可，
但前提是所有手機要跟這台電腦連同一個 WiFi/熱點。
